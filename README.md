 # About

 The Friend Fun Facts Form is just a basic single-file HTML form. Designed to gather info for friend trivia, etc. 

 # How to Use

 For basic functionality, just send the link `https://briannebr.github.io/friend-fun-facts-form` to friends.
 
 Note: By default, the “submit” button won’t work.
 Append `/#mailto=<YOUR-EMAIL-ADDRESS>` to the end of the URL before sending to enable the “Submit” button, which uses basic “mailto” functionality to open the user’s default email client with their responses pre-formatted in an email to you. 

 mailto doesn’t work the best on all devices, so a backup “copy” button is available for users to copy their response data to the clipboard manual sharing.
